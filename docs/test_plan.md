## 前回テスト（2026-06-30）から追加・変更された機能

| 機能 | 内容 |
|---|---|
| REQUESTED ステータス | 閾値割れ時に自動で NONE→REQUESTED に遷移 |
| キャンセル機能 | REQUESTED アイテムを NONE に戻せる（Home・管理画面） |

| ARRIVED+消費バグ修正 | ARRIVED 中に消費して閾値割れ→REQUESTED に自動遷移するよう修正 |

## T14: 複合シナリオ

### シナリオA: 消耗品の注文から補充まで（基本フロー）
1. [ ] AddItem でアイテム登録（初期在庫 = 閾値と同じ値）
2. [ ] Consume で1つ消費 → Home「承認待ち」パネルに出る
3. [ ] Home で「注文した」→ ORDERED になりパネルから消える
4. [ ] Restock の注文済みセクションに表示される
5. [ ] 入荷 → ARRIVED に遷移
6. [ ] Home「到着確認」パネルに表示される
7. [ ] 「確認した」→ NONE に戻り消える

### シナリオB: ARRIVED 中に在庫切れになるケース（★新規）
1. [ ] ORDERED アイテムを Restock で入荷 → ARRIVED
2. [ ] Home「到着確認」に表示されていることを確認
3. [ ] 確認せずに Consume で閾値以下まで消費
4. [ ] ステータスが自動で REQUESTED になる
5. [ ] Home「到着確認」から消え、「承認待ち」に移動する

### シナリオC: 試薬の発注から到着まで
1. [ ] ReagentRequest で試薬をリクエスト
2. [ ] Home「承認待ち」パネルに試薬カードが出る
3. [ ] 試薬カードの「発注へ」を押すと試薬管理に遷移する
4. [ ] ReagentManage で「発注した」→ ORDERED
5. [ ] Home「承認待ち」から消えることを確認
6. [ ] Restock で「到着」
7. [ ] Home「到着確認」に試薬カードが出る
8. [ ] 「確認した」→ 消えてリロードでも消えたまま

### シナリオD: 試薬リクエストのキャンセル（★新規）
1. [ ] ReagentRequest で試薬をリクエスト
2. [ ] Home「承認待ち」パネルの試薬カードの「キャンセル」を押す
3. [ ] カードがパネルから消える
4. [ ] ReagentManage を開くとリクエストが存在しない
