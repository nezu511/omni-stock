## 今回（2026-07-04）追加・変更された機能

| 機能 | 内容 |
|---|---|
| パスワード認証 | 初回アクセス時にパスワード入力を要求。認証済み端末は localStorage でスキップ |
| バックエンドAPI保護 | 全 `/api/*` が Bearer トークン必須。SSE はクエリパラメータで認証 |
| 型番号・カタログ番号 | 試薬マスタに型番号フィールドを追加。登録・表示・検索に対応 |
| 履歴の取り消し | 消耗品詳細の最新量変更エントリのみ「取り消し」ボタンを表示 |
| ステータス自動戻し | 履歴取り消し時に、自動遷移したステータスも一緒に元に戻す |
